# 外形仕様変更時のドキュメント追随責務

本リポジトリの公開API・CLI・設定項目・利用手順・機能一覧など、ユーザから見える外形仕様が変わる開発作業では、当該変更を含むタスクの受け入れ条件に README/docs/API ドキュメント/Wiki の追随更新を含めることを責務とする。作業着手時に外形仕様変更の有無を判定し、変更がある場合は該当ドキュメントの更新を作業スコープに含める（または同一マイルストーン内に別タスクとして追加する）。Wiki更新を伴う場合は、「README は入口（概要・Quick Start・その版に縛られる情報）、版に縛られない解説は Wiki に置く」「README と Wiki は英語を正とし、日本語の写しを併設する」という決まりに従い、push前に人間確認を経ること。

2026-07-24、人間により確立。
