# Maplat API Reference

This directory holds the release-dependent API signatures of `@maplat/ui`.
The conceptual explanation and usage patterns live in the
[Wiki API-Reference](https://github.com/code4history/Maplat/wiki/API-Reference)
(release-independent reading material).

- [`<maplat-ui>` Custom Element](maplat-ui-element.md) — attributes and
  properties, state, methods, events, `::part()` / CSS variables, and the

- [MaplatUi class](maplat-ui.md) — static methods, constructor, instance methods
- [MaplatAppOption](maplat-app-option.md) — option object properties
- [Migration from the legacy UI DOM (Shadow DOM)](migration-ui-shadow-dom.md) — `::part` / CSS variables mapping (Japanese)
